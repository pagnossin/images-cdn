Images CDN: live prototype

3 nodes, NATS JetStream replication log, this page is the gateway (load balancer). loading

Demo scenarios

  1. R1, replication: upload an image and watch it appear on every node in the table below.
  2. R2, read before sync: pause replication on node3, upload an image to node1, then GET it from node3. The response says X-Cache: PEER-FETCH: node3 fetched it from an owner. Resume replication afterwards.
  3. R3, recovery: crash node3, upload a few images, start node3 again. Its pending events drop to 0 as it replays the log from where it stopped.
